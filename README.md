# BudgetPro native releases

This public repository contains the native Android and Windows packaging shells and official installer releases for [BudgetPro](https://budgetpro-afq2.onrender.com/).

The BudgetPro application source and user data are not stored here. The native shells securely load the deployed BudgetPro service, and this repository builds signed APK and Windows installer updates whenever the deployed source revision changes.
