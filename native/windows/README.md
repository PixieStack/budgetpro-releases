# BudgetPro Windows

Electron/NSIS wrapper for the deployed BudgetPro application. The preload bridge is the only way the web UI identifies a real installed Windows application and exposes native update controls.

- Development: `npm install && npm start`
- Installer: `npm run dist`
- Production updates: GitHub Releases through `electron-updater`

The production installer is generated by `.github/workflows/native-release.yml`.
